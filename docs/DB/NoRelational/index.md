# 非关系型数据库

非关系型数据库（NoSQL）没有统一的表结构，按数据模型分为键值、文档、列族、图等类型，主要面向高性能、高并发和灵活扩展场景。

## 分类

| 类型 | 代表产品 | 典型场景 |
| --- | --- | --- |
| 键值型 | Redis | 缓存、会话、计数器 |
| 文档型 | MongoDB | 灵活结构、日志、内容管理 |
| 列族型 | HBase、Cassandra | 海量数据、时序分析 |
| 图数据库 | Neo4j | 社交关系、推荐、知识图谱 |

## 核心特点

- 灵活的数据模型：无需预定义表结构
- 高性能读写：面向大规模数据和高并发
- 水平扩展：分布式架构更容易横向扩容
- 通常弱化事务，换取性能（具体取决于产品）

## 适用场景

- 缓存与高并发读（Redis）
- 半结构化、非结构化数据存储（MongoDB）
- 海量日志与监控数据
- 与关系型数据库组成混合架构
