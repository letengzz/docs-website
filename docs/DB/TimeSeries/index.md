# 时序数据库

<p style="text-align:center;"><img src="./assets/tsdb-logo.png" style="zoom:75%;" /></p>

时序数据库（Time-Series Database，TSDB）是**为"随时间不断追加的测量值"专门设计的存储引擎**：写入只追加、查询按时间范围聚合、过期数据整块丢弃。设备监控、指标采集、IoT 上报、金融行情这些场景，用它比用关系型数据库省一个数量级的成本。

本专题从数据模型讲到存储引擎，覆盖 InfluxDB 与 TDengine 两套主流实现，最后用一个设备监控平台走完"采集 → 写入 → 降采样 → 看板 → 告警"的完整链路。

## 一句话理解

::: tip 一句话理解
关系型库是"账本"（要能改、要对得上账），时序库是"心电图"（只往后画、按时间看趋势、过期就裁掉）。**用错引擎，不是调优能解决的**。
:::
