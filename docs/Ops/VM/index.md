# 虚拟机

虚拟机是**基础设施层**的一种交付形态：把一台物理机的资源切分给多个相互隔离的客户机操作系统，每个客户机自带内核。

## 与容器的边界

| 维度 | 虚拟机 | 容器 |
| --- | --- | --- |
| 隔离边界 | 硬件虚拟化（Hypervisor），各自有内核 | 内核命名空间 + cgroup，共享宿主内核 |
| 启动时间 | 数十秒到分钟级 | 亚秒到数秒 |
| 镜像体积 | GB 级 | MB 级（分层复用） |
| 典型用途 | 异构内核、内核参数调优、强隔离、遗留系统 | 同内核的服务化部署与弹性伸缩 |

判据一句话：**需要自己的内核（异构操作系统、改内核参数、合规要求的强隔离）就用虚拟机；只需要进程级隔离就用容器**。两者可以在同一套编排里共存——把容器跑在虚拟机里是多数云上的默认形态，而不是二选一。

## 运维关注点

- **模板与不可变**：从镜像模板克隆、不在运行中的机器上手工改配置，否则「这台为什么不一样」会变成长期悬案。
- **快照不等于备份**：快照依附于磁盘链路，磁盘损坏时快照一起丢；备份必须是独立介质上的完整副本。
- **时钟与许可**：克隆后先处理主机名、IP、机器 ID 与授权绑定，否则会出现同一授权跑在多台上。
