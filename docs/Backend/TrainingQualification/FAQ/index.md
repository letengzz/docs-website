# 常见问题与分诊

这一页写给「线上已经出事了」的人：先按症状定位到段，再按段查证据，最后才是改代码。十二条分诊覆盖了本专题量出来的绝大多数故障形态。

## 二、止血五步

线上出问题时的顺序，与写代码时相反——先缩小影响面，再找根因：

1. **停**：把判定点从「放行」切到「拦截 + 人工放行」。宁可让人排队，也不要让不该进的人进。
2. **锁**：冻结矩阵与题库的写入（`position_req`、`exam` 只读），避免边改边查。
3. **留**：立刻导出一份「当前有效证书」快照（含 `as_of` 与生成时间），后面所有排查都以它为基准。
4. **查**：按分诊表定位到段，只查那一张表，不要全库翻。
5. **补**：修完数据后，用同一份快照重算一次报表，与修复前对照——差异必须能逐条解释。

::: danger 止血时最容易犯的三个错
1. **先改代码再导快照**：修完之后没有基线，无法证明「修好了」。
2. **直接改 `cert_status` 让报表变绿**：这是把数据缺陷藏起来，下次审计会一次性爆发。
3. **在业务高峰期做全量重算**：本机 6,598 张证重算不到 1 秒，但真实库常常是百万级，必须分批。
:::

## 三、十二问

**Q1：有证但没上过课，算合规吗？**

算，前提是证书来源是 `EXTERNAL` 且通过发证机关校验。合规看的是「有没有有效资质」，不是「在哪儿学的」。但内部报表应把「外部录入」单独列一列——它的造假风险高于内部签发。

**Q2：学时够了能直接发证吗？**

不建议。学时是投入证据，考核是产出证据。若业务必须「学时达标即发证」，那考核环节要保留抽样复核（例如每 20 人抽 1 人实操）。

**Q3：证书到期当天能不能上岗？**

取决于区间定义。本专题统一用半开区间 `[issue, expire)`：到期当天**不能**上岗。所有查询必须同一口径，否则同一天两个查询会给出不同答案。

**Q4：宽限期给多久合适？**

不超过「补齐周期」。本机按 14 天培训 + 3 天考试 + 5 天制证建模，宽限 7 天是可行下限；给 30 天等于承认「一个月内不需要资质」（本机读数：宽限 30 天会消掉 13.9% 的拦截）。

**Q5：一个人的证被吊销了，历史怎么算？**

按 `revoked_at` 截断：吊销日之前仍按原区间有效，之后无效。除非业务明确「自始无效」（例如考试作弊取得），那要额外一个 `invalid_from` 字段。

**Q6：覆盖率到底该报哪个数？**

报「应培口径」并写明分母。同时在附录给「在册口径」，让读者能对上 HR 的花名册。只报一个数且不写分母的报表，等于没有报表。

**Q7：跨年班次的学时记哪一年？**

按天摊。整批记在开课年会让 0.52% 的学时落错年度，而合规线是按年度判的，这 0.52% 可能正好把人从达标推到不达标。

**Q8：为什么要禁止有效期重叠？**

因为「两条有效证」会让所有 `count(*) = 1` 的判定失效，并且让到期提醒按老证发出（人其实已有新证）。若业务上必须允许重叠（例如提前换证），判定要改成「取最晚到期的那张」。

**Q9：题库多少题合适？**

不是题量问题，是**有效题量**问题。本机 25 题里 3 道无效（12%），剔掉后及格率掉 9.61 点。建议按季度算一次区分度，区分度 ≤0.05 的题停用。

**Q10：判定点放在门禁里，离线怎么办？**

门禁必须有离线名单，且名单带 `roster_ver` 与 `generated_at`。每天约 8 个人的准入状态会变（本机 30 天窗口 274 张），所以日更是底线；吊销这类紧急变更要能单独推送。

**Q11：新员工入职当天没证，怎么排班？**

按「无证不得独立作业」处理：可安排在有证人员陪同下作业，系统里记 `supervised_by`。不要给新员工发一个「临时有效」的假证——那会污染整条链的证据。

**Q12：这套东西能直接套到供应商资质吗？**

结构可以，主体不行。`emp_no` 换成 `supplier_id`、`position_req` 换成「物料-资质要求」即可，但供应商资质的判定点在下单而不是门禁，见 [采购寻源与准入](../../ProcureToPay/Sourcing/index.md)。

## 四、术语表

| 术语 | 含义 | 易混淆点 |
| --- | --- | --- |
| 资质（qualification） | 从事某类作业的法定或内控要求 | 不是「技能」，技能不一定要证 |
| 有效期（validity） | 半开区间 `[issue, expire)` | 不是「状态字段」 |
| 强制项（mandatory） | 缺了就不能上岗的要求 | 与「建议项」共用一张表，靠 `is_mandatory` 区分 |
| 在场（onsite） | 实际签到累计的时长 | 不等于报名时长 |
| 去重学时（dedup hours） | 同一人同一课程只计一次 | 不等于总学时 |
| 区分度（discrimination） | 高分组正确率 − 低分组正确率 | 不是「难度」 |
| 无效题（non-functional item） | 区分度 ≤0.05 或正确率 ≥0.97 的题 | 不是「错题」 |
| 宽限（grace） | 到期后仍允许作业的窗口 | 不是「延期」，延期要改 `expire_date` |
| 判定点（gate） | 真正发生拦截的位置 | 不是「报表」 |
| 应培（in-scope） | 在岗且岗位有强制要求的人 | 不等于「在册」 |

## 五、判据清单

本页判据族 `TQQ-A` ~ `TQQ-H`，共 8 条。

| 编号 | 判据 | 判定方式 |
| --- | --- | --- |
| `TQQ-A` | 分诊表覆盖七段 | 十二条症状能映射到 ①~⑧ |
| `TQQ-B` | 每条分诊有可执行动作 | 每条都给出命令或字段名 |
| `TQQ-C` | 止血步骤有序 | 停 → 锁 → 留 → 查 → 补，不可交换 |
| `TQQ-D` | 术语表与正文一致 | 术语表 10 条，均在正文出现过 |
| `TQQ-E` | 不承诺「有证=学过」 | 全文无「有证即视为完成培训」类表述 |
| `TQQ-F` | 外部证书单独可查 | 术语与分诊都提到 `source='EXTERNAL'` |
| `TQQ-G` | 跨专题指路真实存在 | 每条外链目标文件存在 |
| `TQQ-H` | 无复盘类内容 | 本页不含「复盘 / 总结 / 回顾」小节 |
