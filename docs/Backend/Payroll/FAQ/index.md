# 常见问题与分诊

<p style="text-align:center;"><img src="../assets/pay-logo.png" alt="薪酬核算与个税社保" style="zoom:75%;" /></p>

薪酬的问题几乎都不是「系统坏了」，而是「两个口径被当成了一个」。这一页给一张分诊表和六条高频问答，目的是让你在五分钟内确定**该看哪一段、该查哪张表**，而不是从工资单第一行开始逐行怀疑。

::: tip 一句话理解
**先定位段，再定位人，最后定位项。** 顺序反了，就会变成「打开工资单从头看到尾」，而 90% 的问题在第一步就能分出去。
:::

本页判据族 `PYQ-A` ~ `PYQ-H`，共 8 条，定义在最后一节。

## 二、六条高频问答

### Q1 为什么这个月实发比上个月少，工资没变？

大概率是累计预扣法跳档。月薪不变时，个税会**前少后多**：本机读数里月薪 30,000 的例子，1~2 月各 510、3 月跳到 1,560、9 月 2,600、12 月 3,400。这不是错误，是累计口径的必然形状。

::: warning 怎么向员工解释
不要解释公式，给三个数就够了：**本月累计应纳税所得额、上月累计已预扣、本月应扣**。三个数一列，「这个月为什么多扣」就变成了「累计额跨了一个档」，员工自己能算。
:::

### Q2 新人第一个月为什么扣税这么少？

因为累计减除费用按**在本单位任职月数**算，首月只扣 5,000（不是扣全年 60,000），专项附加扣除也只从入职当月起累计。所以首月应纳税所得额通常很低。

但要注意反过来的坑：**年中入职却按自然月序号扣**，会多扣 25,000 的减除费用，导致少预扣 2,500 元，年终汇算时员工要补税。见 [个税累计预扣](../IIT/index.md) 第五节。

### Q3 同一个岗位，为什么我的社保比同事扣得多？

因为社保基数不同。基数是「上年月平均工资」，不是「这个月工资」。三个可能：

1. 你去年的奖金多，导致上年月平均工资高。
2. 你今年调过薪，7 月调基后基数变了。
3. **同事的基数漏做了下限/上限**——这是缺陷，不是差异。用 `pay_si_item.base_actual` 对比 `si_base_rule` 一查就知道。

### Q4 补发一笔钱，为什么税扣了快一半？

因为补发并入**支付期**的累计额。12 月补 60,000，会让累计应纳税所得额一次性跨两个档，这一笔按 20%~25% 的边际税率扣。本机读数：全年个税从 23,880 涨到 35,880，多缴 12,000。

能做的只有三件事：优先当期重算（路径 A）、提前告知员工、不要拆月发放。见 [补发与追溯](../RetroPay/index.md)。

### Q5 离职当月的社保谁来交？

按「当月照缴，次月停缴」。离职当天就停缴会造成断月，影响医保连续性与购房/落户资格。同时这一月的个人部分仍要从最后一次工资里扣——**扣不到就形成欠款**，要在结算单里显式记一行，不能默默算了。

### Q6 年终奖怎么发最省税？

三个动作，按顺序：

1. **先算断崖**：36,000 / 144,000 / 300,000 / 420,000 是四个主要断崖，落在断崖上方 1 元到持平点之间，就要么压到断崖值、要么补到持平点（36,001 的持平点是 38,567）。
2. **再比两种口径**：单独计税 vs 并入综合所得，按人算，不要一刀切。本机读数里，月薪 30,000 的人单独立省 6,120。
3. **最后查次数**：一个纳税年度只能用一次单独计税，第二次发放只能并入当月工资。

## 三、止血五步（发现算错了怎么办）

::: danger 顺序不能乱
1. **先冻结，不先改**：把当期 `period` 状态置为 `HOLD`，阻止继续出账与代发。
2. **先算影响面**：涉及几个人、几个期间、差额多少。一句话说不清影响面的，不要动。
3. **先出证据再出方案**：导出受影响的 `emp_id + period + item_code` 清单，作为附件留存。
4. **红冲 + 重出，不改原数**：原单标记 `REVERSED`，新单 `version + 1`，差额落 `pay_adjust`。
5. **最后才通知**：给员工的说明必须包含「差额多少、什么时候补、下个月还会不会变」三件事，缺一件就会变成第二次投诉。
:::

## 四、术语一致表

同一件事在不同系统里有不同叫法，这是薪酬争议的主要来源。本册统一如下：

| 本册用词 | 同义写法（不要混用） | 定义 | 出现在哪 |
| --- | --- | --- | --- |
| 应发 | 税前工资、工资总额 | 各项明细之和，扣款前 | [应发与计薪天数](../GrossToNet/index.md) |
| 实发 | 到手、净额、打卡金额 | 应发 − 个人社保公积金 − 个税 − 其他 | [总览](../Overview/index.md) |
| 公司成本 | 人工成本、CTC | 应发 + 单位社保公积金 | [成本归集](../Ledger/index.md) |
| 计税所得 | 应纳税所得额（月度） | 应发 − 个人社保 − 专项附加 − 5,000 | [个税累计预扣](../IIT/index.md) |
| 累计应纳税所得额 | 累计所得额 | 当年 1 月至本月的累计口径 | [个税累计预扣](../IIT/index.md) |
| 缴费基数 | 社保基数、申报基数 | 上年月平均工资，卡在 60%~300% | [社保公积金](../SocialInsurance/index.md) |
| 归属期 | 所属期、费用期间 | 这笔钱属于哪个月 | [补发与追溯](../RetroPay/index.md) |
| 支付期 | 发放期、实发月 | 这笔钱哪个月打出去 | [补发与追溯](../RetroPay/index.md) |
