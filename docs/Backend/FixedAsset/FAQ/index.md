# 常见问题与分诊

<p style="text-align:center;"><img src="../assets/fa-logo.png" alt="资产台账与折旧摊销" style="zoom:75%;" /></p>

资产模块的问题有个共同点：**问的人说的是结果，答的人要知道过程**。「折旧不对」这句话背后可能是卡片错了、计划错了、凭证错了、或者只是有人手工调了一笔。这一页给一张分诊表和一套止血顺序。

本页判据族 `FAQ-A` ~ `FAQ-H`，共 8 条，定义在最后一节。

## 一、分诊表：从现象到第一现场

| 现象 | 先看哪里 | 最可能的三个原因 | 去哪一页 |
| --- | --- | --- | --- |

| 某张卡的月折旧突然变了 | `asset_change` 该卡记录 | 寿命变更、减值、改良加原值 | [变更](../Movement/index.md) |
| 卡片提不完（末期还有余额） | `dep_schedule` 行数 vs `useful_life` | 计划没重算、末期没调平、中途停提 | [折旧引擎](../Depreciation/index.md) |

## 二、十二问

**Q1：折旧应该从哪个月开始提？**
当月增加次月提、当月减少当月照提。转固日在 3 月，5 月开始提；3 月新增 40 台的折旧，10 月漏提就永远少这一笔（每月 63,333.20，全年 759,998.40）。

**Q2：一台设备的几个部件要不要拆成几张卡？**
问三个问题：寿命差 30% 以上吗、会单独更换吗、单张卡值得管吗。三个都是「是」才拆。主机与电机（10 年 vs 5 年）该拆，焊接在主结构上的加强筋不该拆。

**Q3：寿命改了，以前提的要不要重算？**
不要。寿命是会计估计，改估计只影响未来（未来适用）。重算历史那是追溯，只有在「政策变更」或「前期差错」时才做。

**Q4：减值提了之后，折旧怎么算？**
按减值后的账面价值重新算剩余期折旧。不重算的话，减值等于没提——本机读数里那笔 20,000 的减值，会被后续 30 期多提的折旧原样抵掉（超提 19,999.80）。

**Q5：为什么每张卡的最后一期金额和前面不一样？**
因为前面每期都四舍五入过，累计下来差几分钱，末期取「基数 − 已提」把它补平。不补平的后果：1,000 张卡里 853 张的累计折旧对不上应提金额。

**Q6：折旧要不要一张卡一张凭证？**
不要。按部门汇总出凭证（2,000 张卡 → 5 张），明细留在 `dep_run`。凭证解决「总账对不对」，明细解决「哪张卡错了」。

**Q7：重跑折旧会不会重复计提？**
有 `(period, card_id)` 唯一键就不会，没有就会——本机读数：无唯一键跑三次，200 行变 600 行，费用翻三倍。

**Q8：资产的「原值」到底包含哪些？**
让它「达到预定可使用状态」的直接支出：价款、不可抵扣税费、运输、安装调试、专业人员服务。试运行净收入冲减。培训费、广告费不计入。

**Q9：试运行期间卖出去的样品收入怎么处理？**
冲减在建工程成本，不确认收入。两种口径差 120,000 的资产和 120,000 的十年折旧。

**Q10：盘点扫不到的资产能直接判盘亏吗？**
不能。先分四态，只对「账有实无」的做二次复核，复核确认才出调整单。本机读数里 2.8% 的漏扫率，直接判亏会虚减 191 万。

**Q11：部分处置能不能「注销整卡再按剩余比例重建」？**
不能。金额上恰好相等，但卡号、变更记录、累计折旧明细全断，下次再部分处置时基数就错了。

**Q12：月折旧率保留几位小数？**
不要存率，存金额。如果非存不可，至少 6 位——保留 2 位时 `1/240` 会变成 `0.00`，整栋楼一年不提折旧。

## 三、止血五步

发现折旧或勾稽异常时，按这个顺序动手，**不要先改数据**：

```text
① 冻结       把本期关账标记置为 HOLD，禁止再写 dep_run（避免越改越乱）
② 定位       跑三条勾稽 + 差集查询，拿到「差额」与「差集」两个证据
③ 归属       把差异归到一张卡或一个部门（用金额反查 + 部门分组）
④ 红冲重提   对错误期间红冲，再按正确参数重提；不删除原记录
⑤ 补齐证据   每条调整都要有原因、审批、影响金额，写进 asset_change
```

::: danger 止血时最常犯的三个错
1. **先删数据再查**：`DELETE FROM dep_run WHERE period=?` 之后，除了「重跑一次」再没有别的办法定位原因。
2. **直接改汇总凭证**：改凭证不改明细，下个月勾稽时差额会变成「不明原因」。
3. **在本期修正历史错误**：跨期错误要么追溯调整（改期初），要么在本期做「以前年度损益调整」，不要混在当月折旧里。
:::

## 四、术语表

| 术语 | 英文 | 一句话解释 |
| --- | --- | --- |
| 原值 | Original Cost / Gross Book Value | 达到可用状态前所有可归属支出的合计 |
| 累计折旧 | Accumulated Depreciation | 从起用到今天已摊销的总额（贷方余额） |
| 账面净值 | Net Book Value, NBV | 原值 − 累计折旧 − 减值准备 |
| 净残值 | Salvage / Residual Value | 报废时预计能收回的金额 |
| 折旧基数 | Depreciable Amount | 原值 − 残值（再减减值） |
| 组件折旧 | Component Accounting | 按部件寿命分别建卡、分别计提 |
| 在建工程 | Construction in Progress, CIP | 尚未达到可用状态的资本性支出 |
| 使用寿命 | Useful Life | 预期使用期间，本册一律以「期（月）」计 |
| 减值准备 | Impairment Provision | 可收回金额低于账面价值的差额 |
| 后续支出 | Subsequent Expenditure | 资本化（改良）或费用化（修理）的支出 |
