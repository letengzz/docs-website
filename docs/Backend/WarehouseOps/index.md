# 仓储作业与波次拣选

<p style="text-align:center;"><img src="./assets/wh-logo.png" alt="仓储作业与波次拣选" style="zoom:75%;" /></p>

仓内系统最容易犯的错，不是「算错了」，而是**相信了账**。账上说这个库位有 6 件，人去了一看只有 4 件——系统没有任何一条报错，拣货员按 6 件扫码，剩下 2 件变成「短拣」，包裹照发，客户收到「少 2 件」。

::: tip 一句话理解
**仓储作业不是「库存的附属功能」，而是一条把「账上的数字」变成「车厢里的包裹」的物理流水线。** 这条线上每一步都会改变物理世界，而系统只在少数几步能看见它。
:::

## 这个专题讲什么

从月台到车厢，中间有七道工序，每一道都有自己的「完成」定义，也都有自己的失败方式。本专题按这七段组织：

| 段 | 这一段在做什么 | 产物 | 失败是否安静 |
| --- | --- | --- | --- |
| ① 到货预约 | 决定哪台车、几点、在哪个月台卸 | 预约单 + 月台号 | **显性**（月台满了会拒） |
| ② 收货上架 | 收货点数、质检、决定放哪个库位 | 收货单 + 上架任务 | 安静（多收少收都能过账） |
| ③ 库存记账 | 写库位余量与流水 | `stock_qty` + `stock_txn` | 安静（丢更新不留痕） |
| ④ 波次拣选 | 合并订单、排路径、把货从货位取下来 | 拣货单 + 拣货明细 | 安静（短拣只是数字小一点） |
| ⑤ 复核打包 | 扫码核对、装箱、称重、贴标 | 包裹 + 重量 + 面单 | 安静（小件漏装称不出来） |
| ⑥ 出库交接 | 与承运商按单交接、装车 | 交接单 + 签收 | 安静（少交一箱靠人记） |
| ⑦ 循环盘点 | 抽样、点数、处理差异 | 盘点单 + 调整流水 | **最后一道** |

| 「面单怎么排版、静区多大」 | [面单渲染](../ShippingCarrier/LabelRender/index.md) | 本册只讲「包裹与面单怎么一一对应」 |
| 「几万行库存文件怎么导入」 | [批量数据交换](../BulkDataExchange/Overview/index.md) | 那册讲**文件契约与行级回执**，本册讲**作业本身** |
| 「供应商寄售的货在我仓里怎么算」 | [VMI 与寄售](../SupplierCollaboration/VmiConsignment/index.md) | 那册讲**货权**，本册讲**这批货放哪个货位** |
| 「采购订单怎么变更」 | [采购订单与变更](../ProcureToPay/PurchaseOrder/index.md) | 那册讲**单据版本**，本册讲**实物作业** |

::: info 为什么不并入「库存与预占」
两个册子的判据没有一条可以复用：那一册的核心是「同一件货不能被卖两次」（并发与预占），本册的核心是「同一件货在哪里、谁去取、走了多少路」。合并只会造出一个两万字的怪物，而且两边的读者都不是彼此。
:::

## 版本与标准

仓储作业这一块**没有「大版本」概念**，因此本专题不建版本目录（如 `Spring5/`、`Spring6/` 那种）。三条理由：

1. **换代的是设备与自动化程度**（人工仓 → 货到人 → 立库），而判据未变：不管谁去取货，「库位唯一」「余量 = 期初 + 流水」「短拣可归因」三条一字不差。
2. **并存的差异是选型而不是代际**：同一个仓库里人工区、电子标签区、自动立库区长期共存，差异是同一页上的几个分支，不是两套内容线。
3. **真正需要版本目录的是「同一份代码两套写法」**，而本专题写的是作业模型与数据契约。可参考按大版本组织的先例：[Spring5](../Java/Frame/Spring/Spring5/index.md)、[Vue2](../../Frontend/Frame/Vue/Vue2/index.md)。

涉及外部标准时，本专题引用的是**长期稳定的编号**，而非某一年的版本号：

| 标准 | 编号 | 本专题用它说明什么 |
| --- | --- | --- |
| GS1 物流标签 | AI `(00)` SSCC，18 位 | 托盘 / 箱级唯一标识怎么来（扩展位 + 公司前缀 + 序列参考 + 校验位） |
| 联运通用平托盘 | GB/T 2934 系列 | 托盘平面尺寸决定库位与货架的容量口径（1200×1000 mm 为优先推荐） |
| 条码符号 | ISO/IEC 15417（Code 128）、GS1-128 | 库位码与箱码为什么不能混用同一套校验规则 |

## 判据纪律

| 页 | 判据族 | 这一族管什么 | 条数 |
| --- | --- | --- | --- |
| 总览 | `WHO-A` ~ `WHO-H` | 七段产物齐全、三个「完成」分列、短拣可归因 | 8 |
| 库位模型与容量 | `WHL-A` ~ `WHL-H` | 坐标进主键、编码可排序、容量三上限、混放落库 | 8 |
| 收货与上架策略 | `WHP-A` ~ `WHP-H` | 时间窗半开区间、差异四类、待检不混、箱码幂等 | 8 |
| 库存快照与批次 | `WHS-A` ~ `WHS-H` | 余量 = Σ流水、快照递推、条件更新、FEFO 取批 | 8 |
| 波次与拣选路径 | `WHW-A` ~ `WHW-H` | 波次四约束、坐标排序、库位不重分、短拣带原因 | 8 |
| 复核、打包与交接 | `WHK-A` ~ `WHK-H` | 行/件双计数、称重容差、SSCC 唯一、交接三方一致 | 8 |
| 循环盘点与差异处理 | `WHC-A` ~ `WHC-H` | 抽样口径、按库位冻结、盲盘、调整四铁律 | 8 |
| 作业度量与产能 | `WHM-A` ~ `WHM-H` | 分子分母同量纲、三口径并报、原因分布 | 8 |
| 实战 | `WHX-A` ~ `WHX-H` | 建库一次成功、闭合查询恒 0、负向用例必须失败 | 8 |
| 常见问题 | `WHQ-A` ~ `WHQ-H` | 分诊可落地、止血五步有序、术语一致 | 8 |

每条判据回答三件事：**看什么现象、判成什么、不满足时改哪里**。编号逐页唯一，可被 `utils/audit` 下的判据类巡检机械核对。
