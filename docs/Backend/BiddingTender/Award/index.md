# 定标、公示与合同：三个 3 日、一个 30 日，中间还有一次回头

评标报告交上来了，排名第一的是 A 公司。按流程，三日内公示中标候选人，公示三日，无异议就定标，发出中标通知书，30 日内签合同。

第八天，B 公司提出异议：A 的项目负责人同时在另一个在建项目上任职，属于「有在建项目未完工」。

**整个流程退回到「确定中标人」之前。**

::: tip 一句话理解
定标是整条链上唯一一个**可以倒回去**的环节。倒回去的代价不是时间，是「已经对外公示的信息要撤回、已经发出的通知书要作废」——所以这一步的所有动作都必须是可撤销的，而不是一锤定音的。
:::

本页判据族 `BTW-A` ~ `BTW-H`，共 8 条。

## 一、四个时限，四种起算点

| 动作 | 时限 | 起算点 | 依据 |
| --- | --- | --- | --- |
| 公示中标候选人 | 收到评标报告之日起 3 日内开始 | 评标报告签收 | 条例第五十四条 |
| 公示期 | 不少于 3 日 | 公示开始 | 条例第五十四条 |
| 异议答复 | 收到异议之日起 3 日内 | 异议送达 | 条例第五十四条 |
| 合同签订 | 中标通知书发出之日起 30 日内 | 通知书发出 | 招标投标法第四十六条 |

四个时限的**起算点各不相同**，这是最容易出错的地方。「三日内公示」的起算是「收到评标报告」，不是「评标结束」；「30 日内签约」的起算是「通知书发出」，不是「定标」。

::: danger 起算点写错一天，整条链都不合规
1. **用「评标结束日」当公示起算点**：评标报告可能在评标结束后两天才签收，等于把 3 日压缩成 1 日。
2. **用「定标日」当签约起算点**：通知书可能定标后一周才寄出，30 日从定标算就会提前到期。
3. **公示期按工作日算**：条例写的是「3 日」，不是「3 个工作日」；按工作日算会把春节前的公示拉长到 9 天。
:::

## 二、本机读数：三个数字

300 个项目：

| 指标 | 值 | 说明 |
| --- | --- | --- |
| 中标人放弃 | 12 / 300（**4.00%**） | 需要顺延第二候选人，价格与工期重新核 |
| 中标价 ≠ 合同价 | 38 / 300（**12.67%**） | 合计差 −290,513.61 元 |
| 签约超过 30 日 | 34 / 300（**11.33%**） | 跨年后预算年度对不上 |

第一行值得展开：**4% 的放弃率意味着每 25 个项目就有 1 个要顺延**。而顺延不是「换个人签合同」这么简单：

| 顺延要做的事 | 容易漏的 |
| --- | --- |
| 确认第二候选人仍满足资格条件 | 资格预审的有效期可能已过 |
| 确认其投标仍在投标有效期内 | 投标有效期通常 90 天，顺延可能超期 |
| 重新核价（若招标文件允许） | 多数情形下应按其原投标价签约 |
| 重新公示 | 换了中标人，公示必须重做 |
| 保证金重新处理 | 原中标人的保证金退还与没收判定 |

第二行的 12.67% 差额，问题不在差额本身，在**没有一条记录说明差额来源**。三种可能的解释对应三种处理：暂列金额扣减（合法）、让利（合法但需入合同）、录入错误（缺陷）。

## 三、合同价与中标价：允许调整，但必须可解释

| 情形 | 合同价与中标价关系 | 需要什么材料 |
| --- | --- | --- |
| 正常签约 | 完全相等 | 无 |
| 暂列金额/暂估价调整 | 合同价 ≤ 中标价 | 工程量清单与暂列金额明细 |
| 中标人让利 | 合同价 < 中标价 | 让利承诺函 |
| 增加内容 | 合同价 > 中标价 | 补充协议 + 审批（可能构成实质性变更） |
| 录入错误 | 无规律 | 更正记录 |

第四行最危险：**合同价高于中标价，如果不是因为法定调整，就可能构成「订立背离合同实质性内容的其他协议」**（招标投标法第四十六条）。系统应当把「合同价 > 中标价」单独报出来，而不是混在「有差异」里。

```sql
-- 三类差异分开统计，而不是合成一个「不一致」
SELECT
  SUM(CASE WHEN c.amount = a.award_price THEN 1 ELSE 0 END)              AS equal_cnt,
  SUM(CASE WHEN c.amount < a.award_price THEN 1 ELSE 0 END)              AS lower_cnt,
  SUM(CASE WHEN c.amount > a.award_price THEN 1 ELSE 0 END)              AS higher_cnt,
  ROUND(SUM(c.amount - a.award_price), 2)                                AS total_diff
FROM contract c JOIN award a ON a.project_id = c.project_id;
```

`higher_cnt` 必须单独看。本机 38 个差异项目里，如果按方向拆开，会发现它们并不是均匀分布——**方向本身就是信息**。

## 四、异议与投诉：两条不同的路

| 环节 | 提出时限 | 向谁提 | 答复时限 |
| --- | --- | --- | --- |
| 对资格预审文件异议 | 申请文件截止 2 日前 | 招标人 | 3 日 |
| 对招标文件异议 | 投标截止 10 日前 | 招标人 | 3 日 |
| 对开标异议 | 开标现场当场 | 招标人 | 当场 |
| 对评标结果异议 | 公示期内 | 招标人 | 3 日 |
| 投诉 | 知道或应当知道之日起 10 日内 | 行政监督部门 | 3 工作日决定受理、30 工作日处理 |

关键规则：**对评标结果投诉前，必须先向招标人提出异议**（条例第六十条）。这条「异议前置」在系统里对应一个约束：投诉记录必须能关联到一条已答复的异议。

```sql
-- 投诉必须有前置异议（除条例第二十二、四十四、五十四条规定事项外）
SELECT c.complaint_id FROM complaint c
WHERE c.topic IN ('qualification','document','opening','award_result')
  AND NOT EXISTS (SELECT 1 FROM objection o
                   WHERE o.project_id = c.project_id AND o.answered_at IS NOT NULL);
```

「答复前暂停」也是硬约束：**异议答复期间，招标投标活动应当暂停**（条例第二十二条、第五十四条）。系统里如果不停表，就会出现「一边处理异议、一边发中标通知书」的荒唐状态。

## 五、状态机：定标是可回退的

```text
评标完成 → 公示中 → 公示期满 → 定标 → 发通知书 → 签约 → 履约
             ↑            │        │
             └── 异议成立 ─┘        │
                       └── 中标人放弃 → 顺延 → 重新公示
```

三个回退边：

| 回退边 | 触发 | 影响 |
| --- | --- | --- |
| 公示中 → 评标完成 | 异议成立、需重新评审 | 评分表作废、需重新抽取或原委员会复议 |
| 公示期满 → 公示中 | 顺延第二候选人 | 公示重做，3 日重新计 |
| 发通知书 → 定标 | 中标人放弃/被查实不符 | 通知书作废，保证金处理 |

**状态机必须允许回退，但每次回退都要留一条「为什么」**。不允许回退的系统，最后一定靠「删数据重来」实现回退——那才是真正不可审计的做法。

## 六、合同：三份文件的一致性

签约时要比对三份文件：

| 文件 | 关键字段 | 与谁比 |
| --- | --- | --- |
| 招标文件 | 合同条款、付款方式、工期 | 合同正文 |
| 投标文件 | 报价、承诺、技术方案 | 合同附件 |
| 中标通知书 | 中标价、工期 | 合同金额与工期 |

三份文件一致，合同才成立。常见的不一致有三种：

| 不一致 | 后果 | 判定 |
| --- | --- | --- |
| 合同金额 ≠ 中标价 | 可能构成实质性变更 | 金额比对 |
| 合同工期 ≠ 投标承诺工期 | 投标承诺被稀释 | 工期比对 |
| 付款方式 ≠ 招标文件约定 | 对未中标人不公平 | 条款比对 |

第三条最难查，因为它要求「条款级」的比对，而不是「文件级」的。一个可用的折中是**只比对五个关键条款**：合同价、工期、付款节点、质量标准、违约责任。五个都对上，其余按「已确认」处理。

## 七、本页判据

| 判据 | 断言 | 验证方式 |
| --- | --- | --- |
| `BTW-A` | 公示期 ≥3 日 | 已签约项目中公示不足 3 日的数量为 0 |
| `BTW-B` | 公示在收到评标报告 3 日内开始 | 超期项目数为 0 |
| `BTW-C` | 中标价 = 中标人投标价 | 差异行数为 0（触发器强制） |
| `BTW-D` | 中标人属于本项目 | 中标人不在本项目投标名单中的记录数为 0 |
| `BTW-E` | 合同价差异按方向分开统计 | 报表能分别输出 equal / lower / higher |
| `BTW-F` | 合同价高于中标价必须单独告警 | `higher_cnt > 0` 时产生待办 |
| `BTW-G` | 投诉有前置异议 | 无前置异议的投诉记录数为 0 |
| `BTW-H` | 异议处理期间状态为暂停 | 处于异议中的项目不出现「已发通知书」 |

## 验证方式

```shell
# 1. 公示期不足 3 日的已签约项目（期望 0）
sqlite3 bt.db "select count(*) from award a join contract c on c.project_id=a.project_id
               where julianday(a.public_to)-julianday(a.public_from) < 3;"

# 2. 合同价高于中标价的清单（必须逐条解释，不能只报总数）
sqlite3 bt.db "select c.project_id, a.award_price, c.amount, round(c.amount-a.award_price,2) d
               from contract c join award a on a.project_id=c.project_id
               where c.amount > a.award_price order by d desc;"

# 3. 异议未答复却已发通知书（期望 0）
sqlite3 bt.db "select count(*) from objection o join award a on a.project_id=o.project_id
               where o.answered_at is null and a.public_from is not null;"
```

第 2 步的输出最好为空。不为空时，每一条都要能说清是暂列金额、让利，还是错误——**说不清的那一条，就是审计会盯上的那一条**。

## 参考资料

- 《中华人民共和国招标投标法》第四十五条：中标人确定后，招标人应当向中标人发出中标通知书，并同时将中标结果通知所有未中标的投标人；第四十六条：招标人和中标人应当自中标通知书发出之日起三十日内，按照招标文件和中标人的投标文件订立书面合同，不得再行订立背离合同实质性内容的其他协议。
- 《中华人民共和国招标投标法实施条例》第五十四条：依法必须进行招标的项目，招标人应当自收到评标报告之日起 3 日内公示中标候选人，公示期不得少于 3 日；投标人或其他利害关系人对评标结果有异议的，应当在中标候选人公示期间提出，招标人应当自收到异议之日起 3 日内作出答复，作出答复前应当暂停招标投标活动。
- 《中华人民共和国招标投标法实施条例》第五十五条：国有资金占控股或者主导地位的依法必须进行招标的项目，招标人应当确定排名第一的中标候选人为中标人。
- 《中华人民共和国招标投标法实施条例》第六十条、第六十一条：投诉期限 10 日、异议前置、受理 3 个工作日与处理 30 个工作日。
