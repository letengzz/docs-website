# 复盘杂项常见问题与最佳实践

本页汇总复盘与自我提升中的常见问题：复盘流于形式、知识学了就忘、面试紧张、工具太多等，并给出可直接执行的做法。

## 复盘总流于形式，怎么办

1. **小步复盘**：10 天一次，30 分钟，别等季度。
2. **必须有行动项**：复盘结束前产出 2~3 个 SMART 行动。
3. **用模板**：KPT 三栏填完就散会，防止空谈。
4. **追踪闭环**：下轮复盘先检查上轮行动项完成情况。

## 学了就忘，怎么改善

```text
遗忘是正常的，对抗遗忘靠「提取」不是「重读」：
```

1. 间隔重复：1/3/7/30 天复习。
2. 主动回忆：合上书默写要点。
3. 输出：写文档、画图、讲给别人。
4. 关联：新知识挂到已有知识上（交叉链接）。
5. 实践：写代码比看代码记得牢。

## 面试紧张/答不好

1. 模拟面试：找人问，录音复盘。
2. 四段式答题：结论 → 原理 → 例子 → 权衡，结构化减少紧张。
3. 不会的题：诚实 + 现场推演思路。
4. 面试前用知识地图全量扫描一遍。
5. 把面试当“对话”而不是“审判”。

## 工具太多用不过来

1. 盘点 30 天实际使用的工具，保留高频。
2. 每类只留一个主力工具（如文档：Notion 或 Obsidian）。
3. 新工具试用期 1 周，不习惯就放弃。
4. 先练快捷键和脚本，再谈装新工具。

## 计划总是完不成

```text
完不成通常是计划问题，不是意志力问题：
```

1. 计划要具体：不是“学 Java”，而是“今天写一个线程池 Demo”。
2. 设置最小可执行单元：30 分钟起步。
3. 允许弹性：周计划比日计划抗干扰。
4. 复盘调整：完不成就砍掉，别硬扛。
5. 记录完成率，找到真正的时间杀手。

## 学习输出没时间写文档

1. 模板化：用统一模板，写起来快。
2. 碎片化输出：先记要点，周末整理成文。
3. 复用学习笔记：边学边写，不二次加工。
4. 降低标准：先有再优，先完成再完美。
5. AI 辅助：让 AI 整理初稿，人工校对补充。

## 复盘与自我提升最佳实践清单

::: tip 复盘十诫
1. 复盘要有数据，不凭感觉。
2. 对事不对人，聚焦流程与根因。
3. 行动项必须 SMART + 责任人。
4. 小步复盘（10 天）优于大复盘（季度）。
5. 学习必须输出：写、讲、画、做。
6. 复习靠提取不靠重读。
7. 知识地图每月更新一次。
8. 工具做减法，快捷键做加法。
9. 计划给弹性，执行看完成率。
10. 复盘结果归档，形成个人经验库。
:::

## 验证方式

1. 用「复盘十诫」自检最近一次复盘，列出差距。
2. 建立自己的间隔重复表，执行两周看效果。
3. 完成一次“知识地图更新 + 行动项追踪”闭环。
