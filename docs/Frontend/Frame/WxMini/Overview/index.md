# 微信小程序 概述

微信小程序是一种运行在微信内部的**轻量级**应用程序。

在使用小程序时，**不需要下载安装**，用户**扫一扫**或**搜一下**即可打开应用。它也体现了"用完即走"的理念，用户不用关心安装太多应用的问题。它实现了应用"触手可及"的梦想，应用无处不在，随时可用，但又无需安装卸载。

小程序开发与网页开发不一样，在开始微信小程序开发之前，**需要访问微信公众平台，注册一个微信小程序账号**。

小程序的四大特性：无须安装、用完即走、无须卸载、触手可及

1. 无须安装：体积小，用户感知不到下载的过程。
2. 触手可及：用户 扫一扫 或 搜一下 即可打开应用，通过下拉能访问使用的小程序。
3. 用完即走，无须卸载。
