# 微信小程序 概述

微信小程序是一种运行在微信内部的**轻量级**应用：用户**无需下载安装**，扫码或搜索即可打开，用完即走、无需卸载。它把「应用」的触达成本压到最低，同时通过平台开放能力接入微信的登录、支付、分享与消息体系。

![通过和 App 对比引出小程序特点](./assets/%E9%80%9A%E8%BF%87%E5%92%8C%20App%20%E5%AF%B9%E6%AF%94%E5%BC%95%E5%87%BA%E5%B0%8F%E7%A8%8B%E7%89%B9%E7%82%B9.png)

## 四大特性

| 特性 | 含义 |
| --- | --- |
| 无须安装 | 体积小，用户感知不到下载过程 |
| 触手可及 | 扫一扫、搜一搜、下拉即可进入 |
| 用完即走 | 完成任务即可离开，不必常驻 |
| 无须卸载 | 不占用户桌面，退出即结束 |

![微信小程序使用流程](./assets/01.%E5%BE%AE%E4%BF%A1%E5%B0%8F%E7%A8%8B%E5%BA%8F.gif)

## 与其它形态的对比

| 维度 | 小程序 | 公众号 / H5 | App |
| --- | --- | --- | --- |
| 安装 | 无需安装 | 无需安装 | 需要下载安装 |
| 入口 | 扫码/搜索/分享/小程序列表 | 菜单、链接 | 桌面图标 |
| 能力 | 部分系统能力 + 微信开放能力 | 浏览器能力受限 | 完整系统能力 |
| 体验 | 接近原生 | 依赖浏览器 | 最完整 |
| 发布 | 平台审核后发布 | 随时发布 | 应用商店审核 |
| 适用 | 轻量业务闭环、拉新转化 | 内容传播、活动页 | 重交互、长期留存 |

::: tip 一句话理解
小程序的价值在于**极低的触达成本 + 平台内的流量闭环**；代价是**体积与能力受限、必须过审核**。判断该不该做小程序，先问「用户是否在微信场景里完成这件事」。
:::

::: warning 上手前先想清楚两件事
1. **账号与类目**：注册时选错主体或类目，后期改类目、补资质都很麻烦，先确认业务形态再注册。
2. **能力边界**：小程序不能像 App 那样随意访问系统能力，也不能像 H5 那样随意用 DOM；先确认所需能力平台是否提供。
:::

## 运行架构：双线程模型

小程序不是浏览器页面，它采用**双线程模型**：

| 线程 | 负责 | 说明 |
| --- | --- | --- |
| 逻辑层（App Service） | 执行 JS、处理业务逻辑与数据 | 可调用 `wx.*` API |
| 渲染层（View） | 渲染 WXML/WXSS | 不直接执行业务逻辑 |

两层通过**数据通信**协作：逻辑层调用 `setData` 把数据传给渲染层，渲染层把用户事件回传给逻辑层。这解释了两条重要的性能经验：

1. **`setData` 有通信成本**，数据越大、调用越频繁，代价越高（见 [性能优化](../Performance/index.md)）。
2. **逻辑层与渲染层不能直接互操作**：不能像浏览器那样直接取 DOM 节点，需要用 `wx.createSelectorQuery` 等接口。

## 开始开发前需要准备什么

1. **注册小程序账号**：访问微信公众平台注册，选择主体类型并完成信息登记与类目选择。
2. **获取 AppID**：在后台「开发管理」中查看，用于项目创建与真机调试。
3. **安装微信开发者工具**：用于编码、调试、预览、上传版本。
4. **配置服务器域名**：涉及网络请求时，需在后台配置合法域名（开发阶段可在工具中临时勾选「不校验合法域名」）。

详细的注册、创建项目与目录结构说明见 [基础](../Basic/index.md) 与 [配置文件](../Settings/index.md)。

## 目录与页面结构（最小示例）

```text
miniprogram/
├─ app.js                # 小程序逻辑：App() 注册应用实例
├─ app.json              # 全局配置：页面路径、窗口、tabBar 等
├─ app.wxss              # 全局样式
├─ project.config.json   # 项目配置：AppID、编译设置等
├─ sitemap.json          # 搜索索引配置
└─ pages/
   ├─ index/
   │  ├─ index.js        # 页面逻辑：Page()
   │  ├─ index.json      # 页面配置
   │  ├─ index.wxml      # 页面结构
   │  └─ index.wxss      # 页面样式
   └─ detail/
      └─ ...
```

## 验证方式

1. 注册账号并创建第一个项目，确认能在开发者工具中看到模拟器与编译工具栏。
2. 修改 `app.json` 的窗口标题与页面路径，确认模拟器实时刷新且无报错。
3. 在 `pages/index/index.wxml` 中写一个按钮，点击后通过 `setData` 改变文本，确认渲染层正常更新。
4. 用真机预览扫码打开项目，确认能正常运行（验证 AppID 与账号权限配置正确）。
