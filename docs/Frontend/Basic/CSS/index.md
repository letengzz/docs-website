# CSS

CSS (层叠样式表，Cascading Style Sheets)：一种标记语言，用于给 HTML 结构设置样式，控制网页在浏览器中的**显示外观**的语言。例如：文字大小、颜色、元素宽高等等。

CSS3 现在已被大部分现代浏览器支持，而下一版的 CSS4 仍在开发中。
