# CSS 选择器

CSS 选择器用于选择 HTML 元素。

## 基本选择器

| 基本选择器 | 特点                                          | 用法                   |
| ---------- | --------------------------------------------- | ---------------------- |
| 通配选择器 | 选中所有标签，一般用于清除样式。              | `* {color: red}`       |
| 元素选择器 | 选中所有同种标签，但是不能差异化选择。        | `h1 {color: red}`      |
| 类选择器   | 选中所有特定类名(class值)的元素：使用频率很高 | `.say {color: red}`    |
| ID选择器   | 选中特定id值的元素(唯一)                      | `#earthy {color: red}` |

### 通配选择器

通配选择器可以选中所有的元素

**语法**：

```css
* {
  属性名: 属性值;
}
```

**例**：

```css
* {
  /* 选中所有的元素 */
  color: orange;
  font-size: 40px;
}
```

特殊情况下通过通配符清除所有元素的默认边距和填充，统一不同浏览器的默认样式：

```css
* {
  margin: 0; /* 去除所有元素的外边距 */
  padding: 0; /* 去除所有元素的内边距 */
  box-sizing: border-box; /* 统一盒模型 */
}
```

### 元素选择器

元素选择器为页面中 **某个元素** 统一设置样式。

:::danger

元素选择器无法实现 **差异化设置**，所有的标签元素效果都一样。

:::

**语法**：

```css
标签名 {
  属性名: 属性值;
}
```

**例**：

```css
/* 选中所有h1元素 */
h1 {
  color: orange;
  font-size: 40px;
}

/* 选中所有p元素 */
p {
  color: blue;
  font-size: 60px;
}
```

### 类选择器

类选择器会根据元素的class值，来选中某些元素 (1个元素或者多个元素)。

:::danger

1. 元素的class属性值不带 `.` ，但是 CSS的类选择器中要带 `.`。

2. class值标准为：不要使用纯数字、中文，尽量使用英文与数字的组合，若由多个单词组成，使用 `-` 做连接，例如：`left-menu`，且命名要有意义，做到"**见名知意**"。

3. 一个元素不能写多个class属性：

   ```html
   <!-- 该写法错误，元素的属性不能重复，后写的会失效 -->
   <h1 class="speak" class="big">你好</h1>
   ```

4. 一个元素的class属性，能写多个值，要用**空格**隔开：

   ```html
   <!-- 该写法正确，class属性可以写多个值 -->
   <h1 class="speak big">你好</h1>
   ```

:::

**语法**：

```css
.类名 {
  属性名: 属性值;
}
```

**例**：

```css
/* 选中所有class值为speak的元素 */
.speak {
  color: red;
}
/* 选中所有class值为answer的元素 */
.answer {
  color: blue;
}
```

### ID选择器

ID选择器会根据元素的id属性值，来 **精准的** 选中某个元素。

:::danger

1. id属性值：尽量由字母、数字、下划线(`_`)、短杠(`-`)组成，最好以字母开头，不要包含空格，区分大小写。
2. 一个元素只能拥有一个id属性，多个元素的id属性值不能相同。
3. 一个元素可以同时拥有id和class属性。

:::

**语法**：

```css
#id值 {
  属性名: 属性值;
}
```

**例**：

```css
/* 选中id值为earthy的元素 */
#earthy {
  color: red;
  font-size: 60px;
}
```

## 复合选择器

复合选择器建立在基本选择器之上，由多个基础选择器，通过不同的方式组合而成。

复合选择器可以在复杂结构中，快速而准确的选中元素。

### 交集选择器

交集选择器可以选中 **同时符合** 多个条件的元素。

:::danger

1. 有标签名必须写在前面。
2. id选择器理论上可以作为交集的条件，但实际应用中几乎不用，因为没有意义。
3. 交集选择器中不可能出现两个元素选择器。

:::

**语法**：

```css
选择器1选择器2选择3...选择器n {
  属性名: 属性值;
}
```

**例**：

```css
/* 选中类名为beauty的p元素 */
p.beauty {
  color: blue;
}
/* 选中类名为rich和beauty的元素 */
.rich.beauty {
  color: green;
}
```

### 并集选择器

并集选择器(分组选择器)可以选中多个选择器对应的元素。

:::danger

1. 并集选择器一般竖着写。
2. 任何形式的选择器，都可以作为并集选择器的一部分。
3. 并集选择器，通常用于集体声明，可以缩小样式表体积。

:::

**语法**：

```css
选择器1,
选择器2,
选择器3,
...选择器n {
  属性名: 属性值;
}
```

**例**：

```css
/* 选中id为peiqi，或类名为rich，或类名为beauty的元素 */
#peiqi,
.rich,
.beauty {
  font-size: 40px;
  background-color: skyblue;
  width: 200px;
}
```

### 后代选择器

后代选择器可以选中指定元素中，符合要求的后代元素 (不限层级，包括子元素、孙元素等)。

:::danger

1. 后代选择器，最终选择的是后代，不选中祖先。
2. 结构一定要符合HTML嵌套要求。
3. 父级和子集都可以是任意选择器。

:::

**语法**：

```css
选择器1 选择器2 选择器3 ... 选择器n {} (先写祖先,再写后代)
```

**例**：

```css
/* 选中ul中的所有li */
ul li {
  color: red;
}

/* 选中ul中所有li中的a */
ul li a {
  color: orange;
}

/* 选中类名为subject元素中的所有li */
.subject li {
  color: blue;
}

/* 选中类名为subject元素中的所有类名为front-end的li */
.subject li.front-end {
  color: blue;
}
```

### 子代选择器

子代选择器可以选中指定元素中，符合要求的子元素(儿子元素，仅限一层)。

:::danger

子代选择器最终选择的是子代，而不是父级。

:::

**语法**：

```css
选择器1>选择器2>选择器3>...选择器n {} (先写父,再写子)
```

**例**：

```css
/* div中的子代a元素 */
div > a {
  color: red;
}
/* 类名为person的元素中的子代a元素 */
.person > a {
  color: red;
}
```

### 兄弟选择器

- **相邻兄弟选择器**：可以选中指定元素后，符合条件的**相邻兄弟**元素。

  **语法**：

  ```css
  选择器1 + 选择器2 {
  }
  ```

  **例**：

  ```css
  /* 选中div后相邻的兄弟p元素 */
  div + p {
    color: red;
  }
  ```

- **通用兄弟选择器**：可以选中指定元素后，符合条件的**所有兄弟**元素。

  **语法**：

  ```css
  选择器1 ~ 选择器2 {
  }
  ```

  **例**：

  ```css
  /* 选中div后所有的兄弟p元素 */
  div ~ p {
    color: red;
  }
  ```

### 属性选择器

属性选择器可以选中属性值符合一定要求的元素。

**语法**：

- 选中**具有**某个属性的元素：`[属性名]`
- 选中包含某个属性，且属性值**等于**指定值的元素：`[属性名="值"]`
- 选中包含某个属性，且属性值以指定的值**开头**的元素：`[属性名^="值"]`
- 选中包含某个属性，且属性值以指定的值**结尾**的元素：`[属性名$="值"]`
- 选中包含某个属性，属性值**包含**指定值的元素：`[属性名*="值"]`

**例**：

```css
/* 选中具有title属性的元素 */
div[title] {
  color: red;
}
/* 选中具有title属性值为header的元素 */
div[title='header'] {
  color: red;
}
/* 选中具有title属性值以h开头的元素 */
div[title='h'] {
  color: red;
}
/* 选中具有title属性值以u结尾的元素 */
div[title='r'] {
  color: red;
}
/* 选中具有title属性值包含ea的元素 */
div[title='ea'] {
  color: red;
}
```

## 伪类选择器

伪类很像类，但不是类，是元素特殊状态的一种描述。

伪类选择器可以选中特殊状态的元素。

### 动态伪类

动态伪类遵循LVHA的顺序，即：link、visited、hover、active。

1. `:link` 超链接未被访问的状态：

   ```css
   /* 选中的是没有访问过的a元素 */
   a:link {
     color: orange;
   }
   ```

2. `:visited` 超链接访问过的状态：

   ```css
   /* 选中的是访问过的a元素 */
   a:visited {
     color: orange;
   }
   ```

3. `:hover` 鼠标悬停在元素上的状态：

   ```css
   /* 选中的是鼠标悬浮状态的a元素 */
   a:hover {
     color: orange;
   }
   /* 选中的是鼠标悬浮状态的span元素 */
   span:hover {
     color: green;
   }
   ```

4. `:active` 元素激活(按下鼠标不松开)的状态：

   ```css
   /* 选中的是激活状态的a元素 */
   a:active {
     color: orange;
   }
   /* 选中的是激活状态的span元素 */
   span:active {
     color: green;
   }
   ```

5. `:focus` 获取焦点的元素

   表单类元素才能使用 `:focus`伪类，当用户点击元素、触摸元素、或通过键盘的 `tab`键等方式，选择元素时，就是获得焦点。

   ```css
   input:focus,
   select:focus {
     color: orange;
     background-color: green;
   }
   ```

### 结构伪类

1. `:first-child`：所有兄弟元素中的**第一个**。

   ```css
   选择器:first-child {
   }
   ```

2. `:last-child`：所有兄弟元素中的**最后一个**。

   ```css
   选择器:last-child {
   }
   ```

3. `:nth-child(n)`：所有兄弟元素中的**第n个**。

   ```css
   选择器:nth-child(n) {
   }
   ```

4. `:first-of-type`：所有**同类型**兄弟元素中的**第一个**。

   ```css
   选择器:first-of-type {
   }
   ```

5. `:last-of-type`：所有**同类型**兄弟元素中的**最后一个**。

   ```css
   选择器:last-of-type {
   }
   ```

6. `:nth-of-type(n)`：所有**同类型**兄弟元素中的**第n个**。

   ```css
   选择器:nth-of-type(n) {
   }
   ```

7. `:nth-last-child(n)`：所有兄弟元素中的**倒数第n个**。

   ```css
   选择器:nth-last-child(n) {
   }
   ```

8. `:nth-last-of-type(n)`：所有**同类型**兄弟元素中的**倒数第n个**。

   ```css
   选择器:nth-last-of-type(n) {
   }
   ```

9. `:only-child`：选择没有兄弟的元素。

   ```css
   选择器:only-child {
   }
   ```

10. `:only-of-type`：选择没有**同类型**兄弟的元素。

    ```css
    选择器:only-of-type {
    }
    ```

11. `:root`：根元素。

    ```css
    :root {
    }
    ```

12. `:empty`：内容为空元素(空格也算内容)。

    ```css
    选择器:empty {
    }
    ```

**n的值**：

1. 0或不写：什么都选不中。
2. n：选中所有子元素。
3. 1~正无穷的整数：选中对应序号的子元素。
4. 2n或even：选中序号为偶数的子元素。
5. 2n+1或odd：选中序号为奇函数的子元素。
6. -n+3：选中的是前三个。

### 否定伪类

使用 `:not(选择器)`来 排除满足括号中条件的元素。

```css
div:not(.abc) {
}
```

### UI伪类

1. `:checked`：被选中的复选框或单选按钮。
2. `:enable`：可用的表单元素 (没有disabled属性)。
3. `:disabled`：不可用的表单元素 (有disabled属性)。

### 目标伪类

可以通过 `:target` 来选中锚点指向的元素

### 语言伪类

可以通过 `:lang()`根据指定的语言选择元素(本质是看lang属性的值)。

## 伪元素选择器

伪元素选择器用于选中元素中的一些特殊位置。

常用伪元素：

- `::first-letter`：选中元素中的**第一个文字**。
- `::first-line`：选中元素中的**第一行文字**。
- `::selection`：选中**被鼠标选中的**内容。
- `::placeholder`：选中输入框的**提示文字**。
- `::before`：在元素**最开始**的位置，创建一个子元素 (必须用content属性指定内容)。
- `::after`：在元素**最后**的位置，创建一个子元素 (必须用content属性指定内容)。

## 选择器优先级

通过**不同的选择器**，选中**相同的元素** ，并且为**相同的样式名**设置**不同的值**时，就发生了样式的冲突，到底应用哪个样式，此时就需要看**优先级**了。

CSS 规则可以同时作用于一个元素，浏览器通过特定规则决定最终生效的样式。**层叠性**解决了样式冲突问题。后定义的样式覆盖先前的样式 (**就近原则**)。

优先级：**行内样式** > **ID选择器** > **类选择器** > **元素选择器** > **通配选择器**

**具体优先级计算方式**：每个选择器，都可计算出一组权重，格式为： (a,b,c)

- a : **ID** 选择器的个数。

- b : **类、伪类、属性** 选择器的个数。

- c : **元素、伪元素** 选择器的个数。

**例**：

| 选择器                    | 权重    |
| ------------------------- | ------- |
| `ul>li`                   | (0,0,2) |
| `div ul>li p a span`      | (0,0,6) |
| `#header .slogan`         | (1,1,0) |
| `#header .slogan a`       | (1,1,1) |
| `#header .slogan a:hover` | (1,2,1) |

**比较规则**：按照**从左到右**的顺序，依次比较大小，当前位胜出后，后面的不再对比。

**例**：

> (1,0,0) > (0,2,2)
>
> (1,1,0) > (1,0,3)
>
> (1,1,3) > (1,1,2)

**特殊规则**：

1. **行内样式**权重大于**所有选择器**。

2. `!important` 的权重，大于**行内样式**，大于**所有选择器**，**权重最高！**
