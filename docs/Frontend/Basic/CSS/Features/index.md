# CSS 三大特性

## 层叠性

如果发生了样式冲突，那就会根据一定的规则 ([选择器优先级](../Selectors/index.md#选择器优先级))，进行样式的层叠 (覆盖)。

样式冲突：元素的**同一个样式名**，被设置了**不同的值**，这就是冲突。

## 继承性

子元素会自动拥有**其父元素**、或**其祖先元素**上所设置的**某些样式**，但是子元素定义自己样式，会优先自己样式。

规则：优先继承**离得近**的。

常见的可继承属性：text-?? ， font-?? ， line-?? 、 color ......

备注：参照[**MDN**](https://developer.mozilla.org/zh-CN/)网站，可查询属性是否可被继承。

## 优先级

> !important > **行内样式** > **ID选择器** > **类选择器** > **元素选择器** >* > **继承的样式**

优先级需要计算权重。

计算权重时需要注意：**并集选择器的每一个部分是分开算的**。
