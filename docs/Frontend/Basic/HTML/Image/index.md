# HTML 图片标签

使用`<img>`标签在网页中显示图片。img标签属于单标签 (空元素)，默认包含两个属性：src和 alt。

## 属性

:::danger

1. 属性采取**键值对**形式。 属性="值"。
2. 属性之间没有必要的先后顺序。
3. 但是属性之间必须有**空格分隔**。

:::

**属性**：

- src 属性：指向要插入到页面的**图像地址**。
- alt 属性：**备选文本**，用于在图片无法显示或者因为网速慢情况下显示的文字，盲人阅读器也会朗读alt 属性的值。
- width：设置图片宽度 (建议css修改，宽度和高度修改其中一个即可，会按照等比例缩放，否则修改图片的宽和高，可能会造成比例失调)。
- height：设置图片高度 (建议css修改，宽度和高度修改其中一个即可，会按照等比例缩放，否则修改图片的宽和高，可能会造成比例失调)。
- title：图像标题。鼠标悬停显示的文本。

## 语法

```html
<img src="" alt="" /> <img src="pig.jpg" alt="佩奇" />
```

## 图片格式

- **jpeg / jpg**：有损压缩格式。

  主要特点：**支持的颜色丰富、占用空间较小**、不支持透明背景、不支持动态图，放大缩小会变得模糊或有锯齿。

  适用场景：对图片细节**没有极高要求**的场景，例如：摄影照片、网页图片（非透明背景）。

- **png**：无损压缩格式。

  主要特点：**支持的颜色丰富**、占用空间略大、**支持透明背景**、不支持动态图。

  适用场景：想让图片有透明背景、想更高质量的呈现图片，例如：Logo、网页图形、需要透明度的图像。

- **bmp**：不进行压缩的一种格式，在最大程度上保留图片更多的细节。

  主要特点：**支持的颜色丰富、保留的细节更多**、占用空间极大、不支持透明背景、不支持动态图。

  使用场景：对图片细节**要求极高**的场景，例如：一些大型游戏中的图片 。

- **GIF**：支持动画，最多256色 (索引色)。

  主要特点：支持的颜色较少、**支持简单透明背景、支持动态图**。

  使用场景：简单动画、表情包、低色彩图形。

- **webp**：Google 开发的现代格式。支持有损/无损压缩、透明度和动画。

  主要特点：具备上述几种格式的优点，但兼容性不太好，一旦使用务必要解决兼容性问题。

  使用场景：网页优化（替代JPEG/PNG/GIF）代表：淘宝等。

- **avif**：基于AV1视频编码，支持高压缩率和HDR。压缩效率优于WebP。
  适用场景：未来网页优化，需高性能压缩的场景 (B站、京东等)。

- **base64**：一串特殊的文本，要通过浏览器打开，传统看图应用通常无法打开。

  使用场景：一些较小的图片，或者需要和网页一起加载的图片。

:::info 使用建议

- 网页优化：优先WebP/AVIF（兼容时），备选JPEG/PNG。
- 透明图像：PNG（静态）或WebP（动态）。
- 动画：WebP/GIF（简单动画）。
- 其他格式：图片还有其他格式，比如svg、HEIC等。

开发中设计师提供图片，直接使用即可。

:::

## 路径

在HTML中，路径用于指定文件 (如图像、样式表或其他网页) 的位置。

- 相对路径：相对于当前文件位置的路径。
- 绝对路径：从根目录开始的完整路径。

### 相对路径

相对于当前文件位置的路径。同一目录：直接使用文件名即可。相对路径依赖的是当前位置，后期若调整了文件位置，那么文件中的路径也要修改。

当前文件夹：使用`./` 表示当前文件夹。

:::tip

相对路径中的 ./ 可以省略不写。

:::

```html
<img src="pig.jpg" alt="佩奇" /> <img src="./pig.jpg" alt="佩奇" />
```

下级子目录：使用目录名/文件名

```html
<img src="img/pig.jpg" alt="佩奇" />
```

上级目录：使用 `../` 返回上一级

```html
<img src="../pig.jpg" alt="佩奇" />
```

### 绝对路径

绝对路径是从根目录开始的完整路径，包含完整的 URL 地址。

:::tip

使用本地绝对路径，一旦更换设备，路径处理起来比较麻烦，所以很少使用。

使用网络绝对路径，确实方便，但要注意：若服务器开启了防盗链，会造成图片引入失败。

:::

从盘符开始：

```html
<img src="E:\HTML5\代码\pic.jpg" alt="示例图片" />
```

完整地址：

```html
<img src="https://www.example.com/images/pic.jpg" alt="示例图片" />
```
