## 创建网页

**操作步骤**：

1. 鼠标右键 => 新建 => 文本文档 => 输入以下内容，并保存。

   ```html
   <marquee>Hello World！</marquee>
   ```

2. 修改后缀为 .html ，然后双击打开即可。这里的后缀名，使用 `.htm` 也可以，但推荐使用更标准的 `.html` 。

3. 程序员写的叫 **源代码**，要交给浏览器进行渲染。

4. 借助浏览器看网页的 **源代码**。

   具体操作：在网页空白处：鼠标右键 ==> 查看网页源代码

## HTML 标签

**标签** 又称 **元素**，是HTML的基本组成单位。

:::tip

标签名不区分大小写，但推荐小写，因为小写更规范。

:::

标签分为：**双标签** 与 **单标签** (绝大多数都是双标签)。

- **双标签**：

  <img src="./assets/%E5%8F%8C%E6%A0%87%E7%AD%BE.jpg" style="zoom:20%;" />

  **例**：

  ```html
  <marquee>Hello World！</marquee>
  ```

- **单标签**：

  <img src="./assets/%E5%8D%95%E6%A0%87%E7%AD%BE.jpg" style="zoom:20%;" />

  **例**：

  ```html
  <input />
  ```

## HTML 标签关系

并列关系：也称为兄弟关系。

```html
<head></head>
<body></body>
```

嵌套关系：也称为父子关系。

```html
<head>
  <title></title>
</head>
```

## HTML 标签属性

用于给标签提供 附加信息。

可以写在**起始标签**或**单标签**中，形式如下：

<img src="./assets/%E6%A0%87%E7%AD%BE%E5%B1%9E%E6%80%A7.jpg" style="zoom:25%;" />

```html
<marquee loop="1" bgcolor="orange">Hello World！</marquee> <input type="password" />
```

有些特殊的属性，没有属性名，只有属性值：

```html
<input disabled />
```

:::danger

1. 不同的标签，有不同的属性，也有一些通用属性。

2. 属性名、属性值不能乱写，都是W3C规定好的。

3. 属性名、属性值，都不区分大小写，但推荐小写。

4. 双引号，也可以写成单引号，甚至不写都行，但还是推荐写双引号。

5. 标签中不要出现同名属性，否则后写的会失效：

   ```html
   <input type="text" type="password" />
   ```

:::

## HTML 基本结构

在网页中，查看某段结构的具体代码：点击鼠标右键，选择"检查"。

"检查" 和 "查看网页源代码" 的区别：

- "查看网页源代码"看到的是：程序员编写的源代码。

- "检查"看到的是：经过浏览器 "处理" 后的源代码。

  备注：日常开发中，"检查"用的最多。

网页的基本结构：

1. `<html>`元素包裹了页面中所有的内容，有时被称为根元素。在HTML中，lang用于声明网页的主要语言，帮助浏览器、搜索引擎等正确处理页面内容。
2. 想要呈现在网页中的内容写在body 标签中。
3. head 标签中的内容不会出现在网页中，包含了文档的元 (meta)数据，主要保存供机器处理的信息，而非人类可读信息。
4. head 标签中的 title 标签可以指定网页的标题。

<img src="./assets/%E7%BD%91%E9%A1%B5%E5%9F%BA%E6%9C%AC%E7%BB%93%E6%9E%84.jpg" style="zoom:25%;" />

```html
<html>
  <head>
    <title>网页标题</title>
  </head>
  <body>
    ......
  </body>
</html>
```

## HTML 注释标签

在HTML中，注释标签用于添加不会在浏览器中显示的注释或说明，不会呈现到页面中，但源代码中依然可见。

```html
<!--这里是注释内容-->
```

**作用**：对代码进行解释和说明。

**特点**：

1. 注释内容不会显示在网页上。

2. 可以跨越多行。

3. 常用于代码说明、临时禁用代码或给其他开发者留言。

注释不可以嵌套，以下这么写是错的 (反例)：

```html
<!--
  我是一段注释
  <!-- 我是一段注释 -->
-->
```

## HTML 文档声明

文档声明用于告诉浏览器当前网页的版本。

旧写法：要依网页所用的HTML版本而定，写法有很多。具体有哪些写法请参考 ： [W3C官网-文档声明](https://www.w3.org/QA/2002/04/valid-dtd-list.html) (了解即可)。

新写法：一切都变得简单了！W3C 推荐使用 HTML 5 的写法。

:::danger

文档声明，必须在网页的第一行，且在html 标签的外侧。

:::

HTML5写法：

```html
<!DOCTYPE html>
```

## HTML 标准结构

HTML标准结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>我是一个标题</title>
  </head>
  <body></body>
</html>
```

配置 VScode 的内置插件emmet ，可以对生成结构的属性进行定制：**输入`!` ，随后回车即可快速生成标准结构**。

在存放代码的文件夹中，存放一个favicon.ico 图片，可配置网站图标。

## HTML 常用标签

不要用 `<br>` 来增加文本之间的行间隔，应使用`<p>` 元素，或CSS margin 属性。

`<hr>` 的语义是分隔，如果不想要语义，只是想画一条水平线，那么应当使用CSS 完成。

| 标签名        | 标签含义   |
| ------------- | ---------- |
| `<br />`      | 换行       |
| `<hr />`      | 分割       |
| `<pre></pre>` | 按原文显示 |
