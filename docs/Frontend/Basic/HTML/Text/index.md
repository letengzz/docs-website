# HTML 文本标签

文本标签用于包裹：词汇、短语等。通常写在排版标签里面。排版标签更宏观 (大段的文字)，文本标签更微观 (词汇、短语)。**文本标签通常都是行内元素**。

:::warning

1. blockquote 与 address 是块级元素，其他的文本标签，都是行内元素。
2. 有些语义感不强的标签，很少使用，例如：small 、b 、u 、q 、blockquote。

:::

| 标签名                       | 标签语义                                                         |
| ---------------------------- | ---------------------------------------------------------------- |
| `<em></em>`                  | 要着重阅读的内容 (切斜)                                          |
| `<strong></strong>`          | 十分重要的内容 (加粗)                                            |
| `<span></span>`              | 没有语义，用于包裹短语的通用容器                                 |
| `<cite></cite>`              | 作品标题 (书籍、歌曲、电影、电视节目、绘画、雕塑)                |
| `<dfn></dfn>`                | 特殊术语 ，或专属名词                                            |
| `<del></del>`与`<ins></ins>` | 删除的文本与插入的文本                                           |
| `<sub></sub>`与`<sup></sup>` | 下标文字与上标文字                                               |
| `<code></code>`              | 一段代码                                                         |
| `<samp></samp>`              | 从正常的上下文中，将某些内容提取出来，例如：标识设备输出         |
| `<kbd></kbd>`                | 键盘文本，表示文本是通过键盘输入的，经常用在与计算机相关的手册中 |
| `<abbr></abbr>`              | 缩写，最好配合上title 属性                                       |
| `<bdo></bdo>`                | 更改文本方向，要配合dir 属性，可选值: ltr (默认值)、rtl          |
| `<var></var>`                | 标记变量，可以与code 标签一起使用                                |
| `<small></small>`            | 附属细则，例如：包括版权、法律文本                               |
| `<b></b>`                    | 摘要中的关键字、评论中的产品名称                                 |
| `<i></i>`                    | 多用于呈现字体图标                                               |
| `<u></u>`                    | 与正常内容有反差文本，例如：错的单词、不合适的描述等             |
| `<q></q>`                    | 短引用                                                           |
| `<blockquote></blockquote>`  | 长引用                                                           |
| `<address></address>`        | 地址信息                                                         |

HTML 5 新增文本标签：

- **文本注音**：使用 `<ruby>`包裹需要注音的文字，使用 `<rt>`写注音， rt 标签写在 ruby 的里面。

  ```html
  <ruby>
    <span>魑魅魍魉</span>
    <rt>chī mèi wǎng liǎng </rt>
  </ruby>
  ```

- **文本标记**：使用 `<mark>` 标签来标记。

  :::danger

  W3C 建议 mark 用于标记搜索结果中的关键字。

  :::
