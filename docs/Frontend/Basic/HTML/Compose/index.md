# HTML 排版标签

## 标题标签

标题标签为h1~h6一共6级。

:::tip

- **显示特点**：标题文字会加粗显示，并且每行只显示一个。
- **h1唯一性**：h1最好每个页面使用一次，一般用于文章标题或者logo。
- **层次性**：在现有的六个标题层次中，除非觉得有必要否则应该争取每页使用不超过3级。

:::

**语法**：

```html
<h1>这是h1标题</h1>
<h2>这是h2标题</h2>
<h3>这是h3标题</h3>
<h4>这是h4标题</h4>
<h5>这是h5标题</h5>
<h6>这是h6标题</h6>
```

## 段落标签

HTML元素表示文本的一个段落。

:::tip

每行只显示**一个**，文字显示不开会**自动换行**段落的相关样式请用CSS设置。

:::

**语法**：

```html
<p>段落文本</p>
```
