# 核心概念总览

OpenClaw 是一个功能强大的 AI Agent 框架。理解其核心概念是高效使用 OpenClaw 的基础。

## 概念地图

OpenClaw 的各个核心概念之间存在紧密的关联。

OpenClaw 的运作方式：

```text
┌──────────────────────────────────────────────────────────────┐
│                        OpenClaw 核心架构                       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌─────────┐    ┌─────────────┐    ┌───────────────────┐     │
│  │ Channel │───▶│   Gateway   │───▶│      Agent        │     │
│  │  渠道    │    │    网关      │    │     智能体        │     │
│  └─────────┘    └─────────────┘    └────────┬──────────┘     │
│                      │                      │               │
│                      ▼                      ▼               │
│               ┌─────────────┐    ┌───────────────────┐     │
│               │  WebSocket   │    │     Workspace     │     │
│               │   协议通信    │    │     工作空间       │     │
│               └─────────────┘    └────────┬──────────┘     │
│                                           │               │
│                                ┌──────────┼──────────┐     │
│                                ▼          ▼          ▼     │
│                         ┌─────────┐ ┌─────────┐ ┌──────┐  │
│                         │ Memory  │ │ Skills  │ │ LLM  │  │
│                         │  记忆   │ │  技能   │ │ 模型  │  │
│                         └─────────┘ └─────────┘ └──────┘  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 核心组件关系

| 组件 | 角色 | 说明 |
|------|------|------|
| **Gateway（网关）** | 核心枢纽 | 管理所有消息渠道、WebSocket 连接、消息路由、模型调用和工具调度 |
| **Agent（智能体）** | 执行者 | 拥有记忆、个性和工具能力，基于大模型完成实际任务 |
| **Channels（渠道）** | 入口 | WhatsApp、Telegram、Discord、微信、飞书等消息平台 |
| **Tools（工具）** | 能力层 | 文件操作、命令执行、网页搜索、浏览器控制等具体能力 |

### 数据流概览

```text
用户消息 → Channel → Gateway → Agent → LLM → 工具执行 → 响应生成 → 消息返回
```
