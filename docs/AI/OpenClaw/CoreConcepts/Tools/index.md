# 工具（Tools）

工具是 OpenClaw 智能体实际「动手」的能力：执行命令、操作文件、访问网络。工具调用让 Agent 从「只会聊天」变成「能干活」。

::: info 适用版本
本文基于 OpenClaw 当前工具体系；工具清单与权限配置以官方文档为准。
:::

## 工具是什么

工具（Tool）是 Agent 可以调用的外部能力，通常以函数形式暴露给大模型：

```text
Agent 决定调用工具 → 生成参数 → 工具执行 → 结果返回给 Agent → Agent 继续推理
```

OpenClaw 常见工具：

| 工具 | 能力 |
| --- | --- |
| 命令执行 | 在沙盒/工作空间运行 shell 命令 |
| 文件读写 | 读写、编辑工作空间内的文件 |
| 网页搜索 | 检索网络信息 |
| 浏览器控制 | 打开页面、点击、截图 |
| 记忆检索 | 查询历史记忆（见「记忆系统」） |
| 消息发送 | 通过渠道回复用户 |

## 工具调用的流程

1. 系统提示词描述可用工具和参数格式。
2. 大模型输出工具调用请求（Function Calling）。
3. 框架执行工具并捕获输出。
4. 输出作为上下文返回给大模型。
5. 大模型基于结果生成最终回复或继续调用。

## 工具定义的示例

工具的「说明书」通常包含名称、描述和参数 Schema（概念示意）：

```json
{
  "name": "run_command",
  "description": "在沙盒工作空间中执行 shell 命令，用于文件操作、程序运行等",
  "parameters": {
    "type": "object",
    "properties": {
      "command": { "type": "string", "description": "要执行的命令" },
      "timeout": { "type": "integer", "description": "超时秒数，默认 30" }
    },
    "required": ["command"]
  }
}
```

描述越清晰，模型调用越准确；参数 Schema 越严格，运行时错误越少。

## 工具权限与安全

工具越强大，风险越高。安全基线：

- **最小权限**：默认禁止高风险操作（删除、格式化、外发数据）。
- **沙盒隔离**：命令在独立工作空间/容器中执行，不直接操作宿主。
- **人工确认**：危险操作需要用户确认。
- **白名单**：只允许访问指定目录、域名、会话。
- **审计日志**：记录每次工具调用的参数和结果。

## 工具超时与重试

工具调用必须有超时保护：

- 命令类工具设置默认超时（如 30~60 秒）。
- 网络类工具设置连接超时与读取超时。
- 失败时区分「可重试」（网络抖动）与「不可重试」（参数错误）。
- 返回给模型的结果里包含错误信息，帮助模型换一种方式继续。

## 自定义工具

自定义工具通常需要：

1. 工具名称与描述（大模型据此决定何时调用）。
2. 参数 Schema（JSON Schema 风格）。
3. 执行逻辑与错误处理。
4. 返回给大模型的结果格式。

## 易错点

::: danger 常见错误
1. 给 Agent 开放了删除/清空权限且无确认，误操作不可恢复。
2. 工具描述太模糊，大模型频繁误调或从不调用。
3. 工具执行超时没有处理，Agent 一直等待。
4. 工具输出过大，塞满上下文。
5. 工具结果不可信（如网页内容被污染），Agent 直接照搬。
6. 工具没有超时，一个卡住的命令拖住整个 Agent。
7. 自定义工具没写错误处理，异常信息直接暴露内部细节。
:::

## 验证方式

1. 让 Agent 执行一个只读命令（如 `pwd`），确认工具调用链路正常。
2. 尝试高风险操作，确认被拦截或需要确认。
3. 查看审计日志，确认参数和结果有记录。
4. 给工具输入异常参数，确认错误处理正常。
5. 用一个会卡住的命令验证超时机制。
6. 检查高风险工具是否默认拒绝或要求确认。
