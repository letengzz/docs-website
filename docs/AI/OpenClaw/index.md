# OpenClaw

<p style="text-align:center;"><img src="./assets/openclaw-logo.png" style="zoom:75%;" /></p>

OpenClaw（原名 ClawdBot）是一个开源的 **AI Agent 智能体框架**，它要解决的是「**让 AI 长出双手**」：不仅能理解和生成文本，还能直接操控你的电脑、执行任务、连接你的沟通渠道。本专题从概念到落地逐层展开——它是什么、怎么装、有哪些核心概念、以及怎么自己写一个技能。
