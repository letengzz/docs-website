# 完整项目

完整项目（Complete）用于沉淀**端到端可交付**的实战工程：从需求拆分、数据库设计、前后端联调，到测试、部署、监控与复盘，形成一条完整的交付链路。与 [基础项目](../Base/index.md) 的区别是：基础项目聚焦"工程模板与基础设施"，完整项目聚焦"业务全流程 + 交付"。

## 项目列表

| 项目 | 内容 | 状态 |
| --- | --- | --- |
| [全栈项目实战](FullStackProject/index.md) | 需求拆分、数据库设计、前后端联调、测试、部署、复盘 | **已完成（7 章）** |
| 电商项目实战 | 需求、架构、编码、测试、部署、复盘 | 规划中（占位） |
| 全流程部署实战 | Docker、K8s、CI/CD、监控、回滚 | 规划中（占位） |

> 上述项目按计划逐步建设；建成后在此处替换为可点击的章节链接，并在各项目目录页维护「迭代记录」。

::: info 迭代说明
本目录下的项目**逐步完成**：每次迭代新增或深化一个模块（例如本次新增"监控"章节、下次补充"回滚演练"），并在各项目目录页的「迭代记录」中登记。项目数量保持精简，优先把已有项目写深、写全。
:::

## 与 docs 的关系

- `docs/` 讲原理与用法（例如 [认证与授权](../../docs/Backend/Auth/index.md)、[CI/CD](../../docs/Tools/CICD/index.md)、[Kubernetes](../../docs/Ops/Kubernetes/index.md)）。
- `project/` 把它们串成可照做的工程步骤，并提供完整的文件内容与命令。
